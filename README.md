# Devanshu Kumar — Premium Portfolio V2

This revision reshapes the supplied portfolio toward the visual language of the four provided references: Cohesion, Artemis, Portavia and Luzia. It uses original HTML/CSS/JS rather than copying their source code.

The existing project is built with HTML5, CSS3, JavaScript, GSAP/ScrollTrigger and Lenis. The source already includes smooth scrolling and scroll-triggered motion. 

## Main changes
- Pill-style glass navigation
- Oversized editorial typography
- Playful CSS 3D-style hero objects
- More premium project gallery
- Stronger project-first hierarchy
- Large stats strip
- Service rows with hover motion
- Flip-style toolkit cards
- Editorial process section
- Large testimonial / statement section
- Dark cinematic contact CTA
- Cursor glow and magnetic interactions
- Responsive mobile layout

## Customize
1. Replace `YOUR PHOTO` in the hero.
2. Replace project placeholders with actual MP4/WebM previews or thumbnails.
3. Change `your@email.com`.
4. Add real Instagram, LinkedIn and Behance URLs.
5. Replace placeholder statistics with your actual numbers.
6. Add real case-study links to project cards.

## Run
Open `index.html` directly or use VS Code Live Server.
